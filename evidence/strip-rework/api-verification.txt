## 2. ViewTreeObserver: the internal-insets API (which CAN set a touchable region) is not in the public stub
(no internal-insets member in the public API: addOnComputeInternalInsetsListener is @hide)

## 3. SurfaceControl.Transaction: no input-window / input-region setter (setInputWindowInfo is @hide)
  public android.view.SurfaceControl$Transaction setDamageRegion(android.view.SurfaceControl, android.graphics.Region);

## 4. View: only gesture exclusion (back gesture) and TouchDelegate (view tree), neither is a window input region
  public java.util.List<android.graphics.Rect> getSystemGestureExclusionRects();
  public android.view.TouchDelegate getTouchDelegate();
  public void setSystemGestureExclusionRects(java.util.List<android.graphics.Rect>);
  public void setTouchDelegate(android.view.TouchDelegate);

## 5. Classes an app could use to install a sub-window touchable region are absent from the stub jar
(no InternalInsets/InputWindowInfo/TouchableRegion class in android.jar)
