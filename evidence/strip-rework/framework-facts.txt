D. Why the old 32 dp strip was blamed for the cancel: the framework thresholds
   (24 dp start / 24 dp distance = 48 px) are BELOW the 32 dp (64 px) window
   edge, so the observed DOWN -> MOVE(s) -> CANCEL could equally be either.
   The new logging distinguishes them: a cancel while the window is attached,
   touchable and 512 px tall is NOT a bounds exit, and the strip logs exactly
   that.
