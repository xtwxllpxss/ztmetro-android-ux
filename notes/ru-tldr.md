# Кратко по-русски (заметка; основной текст репозитория — английский)

Этот файл — вспомогательная заметка для владельца проекта. Публичные README и docs
написаны на английском, как требует репозиторий.

## Что выяснено

1. **Собрать «только SystemUI» отдельно нельзя.** SystemUI — платформенно
   подписанное привилегированное приложение из `system_ext`, собирается против
   скрытых API `framework.jar`, ресурсов `framework-res` и библиотеки
   `WindowManager-Shell`, плюс флаги/Compose/SettingsLib/monet. Значит нужен полный
   build-tree: по документации AOSP — 400 ГБ диска (250 checkout + 150 build) и
   64 ГБ RAM. «200–300 ГБ» — это не миф, а реальность.
2. **Подменить SystemUI в официальной LineageOS нельзя**: официальные сборки
   подписаны приватными ключами LineageOS, а SystemUI требует платформенной подписи
   и `sharedUserId`. Варианты: (а) собрать свою LineageOS с собственными ключами и
   форкнуть SystemUI — единственный чистый путь; (б) Magisk-подмена APK — хрупко и
   небезопасно (риск bootloop, подпись/AVB, OTA), не проверено; (в) RRO-оверлеи —
   только цвета/шрифты/размеры, без шторки/локскрина.
3. **Без сборки прошивки достижимо**: лаунчер (Start, плитки, список приложений,
   поиск, live tiles через NotificationListener), свои баннеры-оверлеи (ниже
   статус-бара), своя «шторка» как отдельная activity, RRO-палитра/шрифты (с root или
   предустановкой). Недостижимо: статус-бар, шторка, локскрин, навбар, recents, QS,
   меню питания/громкости.
4. **RAM на 2 ГБ**: Android 16 в Go-конфигурации рассчитан максимум на 2 ГБ, но Go
   отключает PiP, split-screen, system alert windows (оверлеи!) и живые обои — для
   нашей оболочки это плохо. Обычная LineageOS 23.2: база ~0.9–1.2 ГБ + стоковый
   лаунчер 90–180 МБ; ztmetro-лаунчер должен уложиться в 80–150 МБ, вся оболочка —
   ≤250 МБ. Реальные цифры нужно снять на устройстве (протокол в docs/05).
5. **Прецеденты**: полной замены системного UX без пересборки ROM нет ни у кого.
   Есть лаунчеры-косплеи WP (MetroWinLauncher GPL-3, Launcher 10), теминг через
   Substratum/Iconify (root/Xposed), минималистичные прошивки (Light Phone, Punkt,
   Mudita) — все владеют своей прошивкой, и «своя ОС + Android-приложения»
   (Sailfish с проприетарным Alien Dalvik; Ubuntu Touch с Halium + Waydroid).
6. **Рекомендация**: этап 0 — поставить LineageOS-23.2-microG и измерить RAM;
   этап 1 — ztmetro как APK-лаунчер + RRO (2–4 недели); этап 2 — только если
   системный хром критичен: своя сборка LineageOS с своими ключами и форк SystemUI
   (месяцы). ztOS+ATL остаётся веткой «Linux-native», Waydroid на 2 ГБ — не daily
   driver.

## Открытые вопросы

- Реальное поведение Magisk-подмены SystemUI на `lineage-23.2` (подпись, AVB,
  system_ext, OTA) — не проверено.
- Работает ли `settings put global policy_control immersive.*` на этой сборке —
  не проверено.
- Есть ли у SystemUI overlayable-ресурсы в `lineage-23.2` (в AOSP-16 в
  `packages/SystemUI/res/values` не найдено) — нужно грепнуть дерево.
- Фактические цифры PSS/ZRAM/PSI/oom на устройстве — снять по протоколу docs/05.
- Официальный статус `Mi8917` в LineageOS сейчас (23.0 — поддерживался; архив
  microG-сборок живёт до 2026-08) — проверить перед переездом.
